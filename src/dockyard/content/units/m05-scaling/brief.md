## Two workers, optional tools

Prepare starts the known-good Compose stack with one worker.
Use Compose to scale worker to at least two running replicas without assigning a fixed worker container name.
Run the optional inspect service through its tools profile and observe database name resolution.

Submit several jobs through the dashboard or API and inspect the completing worker identities.
Leave at least two worker replicas running and keep the dependency services private.
The live checker verifies replica count and a real result; the optional diagnostic output is a self-review observation.
