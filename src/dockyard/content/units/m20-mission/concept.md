## Build it yourself

This mission puts the first two lessons together: start from two prepared machines and end with Dispatch running and processing jobs.
The helpers from the lessons are still in the workspace, but the order is up to you.
Each step depends on the ones before it, so think about the sequence before you start.

This two-machine cluster is not highly available.
A working job shows everything works together now; it does not show the cluster would survive losing a machine or its storage.
Say so in your handoff.

## Working on your own

Try it without hints first.
Hints and the reference solution are available, but using them marks this attempt as practice with help.
