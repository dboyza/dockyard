## From prepared hosts to an operated application

Prepared guest packages and cached images remove incidental installation work, but the cluster does not exist yet.
Use the preceding lessons to decide the order of initialization, client setup, worker registration, networking, and application deployment.
Each stage establishes a boundary required by the next stage.
This mission supplies the same real tools and checkpoint without an ordered solution in the brief.

The two-guest topology is deliberately not highly available.
Its successful application path proves that the required components work together now, not that they tolerate a host or storage loss.
State those limits in the handoff alongside observed evidence.
